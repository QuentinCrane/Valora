# Screenshots

Put privacy-safe screenshots here before publishing the repository.

Recommended set:

- `hero.png`：README 和 Release 页面可使用的横向宣传图，建议 16:9。
- `home.png`：首页资产总览和日均成本。
- `asset-detail.png`：资产详情、生命周期和目标日均。
- `analytics.png`：趋势、排行和价值复盘。
- `cover-editor.png`：封面或贴纸编辑。
- `settings.png`：备份、同步和小组件入口。

Use demo data only. Do not include personal assets, account names, WebDAV URLs, local paths or private server addresses.
