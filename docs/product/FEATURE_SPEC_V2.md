# Valora App 功能规格 v2

## 1. 产品定位

Valora是一款本地优先的个人资产生命周期管理 App。它不是传统记账软件，而是围绕“物品—价值—使用—转手—复盘”建立个人资产档案。

## 2. 核心页面

### 2.1 首页

- 顶部品牌区：Valora Logo、标语、深色模式入口
- 资产总览看板：当前估值、累计投入、已消耗、平均日耗
- 智能提示：识别日均成本最高或高于目标的资产
- 搜索栏：资产名称、分类、标签、备注
- 筛选区：状态、分类
- 资产清单：资产头像、名称、状态、分类、标签、目标进度、现值、日耗

### 2.2 资产详情

- 大头像和基础信息
- 价格指标：买入价、当前/回收价值、持有天数、日均成本、收益、目标日耗
- 目标进度条
- 备注与标签
- 编辑和删除入口

### 2.3 新增/编辑资产

- 名称、图标、分类
- 买入价、当前估值、卖出价、收益
- 购买日期、目标日耗
- 状态：服役中、闲置中、已卖出、已退役
- 标签和备注

### 2.4 统计

- 分类估值占比
- 日均成本排行
- 生命周期复盘：资产数量、愿望数量、已卖出、闲置中

### 2.5 愿望

- 想买物品列表
- 预计价格、优先级、购买理由
- 完成 / 未完成状态
- 预算汇总

### 2.6 设置

- 深色模式
- 货币符号
- JSON 备份与恢复
- 项目说明

## 3. 计算公式

### 3.1 持有天数

```text
持有天数 = max(1, 当前日期或卖出日期 - 购买日期 + 1)
```

### 3.2 回收价值

```text
若已卖出：回收价值 = 卖出价
否则：回收价值 = 当前估值
```

### 3.3 已消耗成本

```text
已消耗成本 = max(0, 买入价 - 回收价值 - 资产收益)
```

### 3.4 真实日耗

```text
真实日耗 = 已消耗成本 / 持有天数
```

### 3.5 目标日耗进度

```text
进度 = 目标日耗 / max(真实日耗, 0.01)
最终限制在 0 到 1 之间
```
