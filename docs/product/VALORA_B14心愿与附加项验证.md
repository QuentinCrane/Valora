# VALORA B14 心愿与附加项验证

## 范围

- 心愿编辑器加载并保存已有附加项，不再静默保留不可编辑数据
- 资产编辑、快速创建和心愿编辑共用附加项编辑、删除、拖拽排序交互
- 心愿转资产保留附加项顺序、关系标记、显式购买日期和心愿创建时间
- 转换以一次持久化提交为边界，写入失败时恢复资产和心愿内存集合
- 售出价规则统一为：卖出状态允许为空，空值代表未记录回收金额；非卖出状态不保留售出价
- 旧心愿 payload 无 addons 时按空列表兼容读取；旧资产非卖出记录的遗留售出字段会被清理
