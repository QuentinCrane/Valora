# V24 Date / Analytics / Cutout / Widgets Upgrade

## 本轮修复点

1. 日期输入
   - 移除依赖英文系统 DatePicker 的新增页日期交互。
   - 新增中文日期编辑弹层，支持：
     - 手动输入 `2026-05-24`
     - 手动输入 `2026/5/24`
     - 手动输入 `2026年5月24日`
     - 今天 / 昨天 / 本月初 / 上个月 / 下个月快捷按钮
     - 当前月份的圆角日期网格选择
   - 保存时 `parseDate()` 也改为兼容中文日期和斜杠日期，避免用户手输中文日期后被错误回退到今天。

2. 分析页可交互
   - 核心指标卡可点击查看计算口径。
   - 长期价值地图可点击查看每个节点的估算净值。
   - 分类估值占比可点击查看分类明细和占比进度条。
   - 标签分布可点击查看标签资产数量。
   - 服役时长分布可点击查看服役排行，并可从弹层进入资产详情。

3. 日均成本趋势解释
   - 资产详情页的日均成本趋势增加说明：蓝线表示日均成本被使用天数摊薄的过程。
   - 图表下方增加第 1 天日耗、当前日耗、已摊薄金额三项解释。
   - 点击图表可打开“怎么看日均成本趋势”的说明弹层。

4. 首页数值刷新与震动
   - 首页金额不再每次构建/进入都从 0 翻动并触发震动。
   - 只有资产数值真实发生变化时才执行滚动动画和细腻震动。

5. 智能抠图封面
   - Android 原生侧新增 `cutoutImageFromPicker`。
   - 新增页和资产编辑页增加“抠图封面”入口。
   - 当前实现为离线启发式抠图：根据四角背景色估算背景并输出透明 PNG，适合白底/浅色底商品图。
   - 该方案不依赖云服务，不上传图片。复杂背景下效果不如专业分割模型，后续可替换为 ML Kit / MediaPipe 分割。

6. 图标库与视觉
   - 扩展 3D 图标库。
   - 3D 图标从“带背景贴纸卡片”改成“无底色图标 + 周边淡淡光影”。
   - 资产卡片和新增页图标显示会更轻，不再像一块背景色按钮。

7. 桌面小组件
   - 为已有 5 个小组件增加 Android receiver label 和 description，系统小组件列表里会显示更明确的名称。
   - 新增 2 个小组件：
     - Valora｜到期提醒
     - Valora｜资产快照
   - 小组件数量变为 7 个。

## 预测返回说明

本轮进一步移除了 `softRoute()` 对页面的自定义 `PredictiveBackBoundary` 包裹，让二级页面回到更标准的 `MaterialPageRoute`，以减少自定义手势对 Android 系统预测返回的干扰。

测试条件仍然是：Android 13/14+、系统手势导航、开发者选项中启用预测返回动画，并且必须在二级页面从屏幕最左侧边缘慢慢右滑。
