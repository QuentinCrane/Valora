# V25 深色模式与玻璃高光修正报告

## 本轮目标

根据反馈，本轮不继续堆功能，重点修正两个视觉问题：

1. 所有按钮、Dock、保存按钮上的条状高光过于突兀；
2. 深色模式过于“纯黑”，缺少品牌蓝氛围，并且局部文字在深色模式下可读性不足。

## 主要改动

### 1. 去掉条状高光

已移除以下位置的宽条状白色高光：

- 底部 Dock 胶囊顶部的大块反光；
- Dock 选中滑块顶部的白色条状反光；
- 右下角新增按钮顶部的条状反光；
- 新建页保存按钮顶部的条状反光。

保留内容：

- 极细的边缘轮廓光；
- 轻微的边缘折射线；
- 很弱的主题蓝色环境光。

这样不会再出现“按钮上贴了一条白条”的感觉。

### 2. 重做深色模式底色

深色模式不再使用接近纯黑的 `#0B0D0D / #18191A / #1F1F20`，改为深蓝体系：

- 页面背景：`#061522`
- 卡片背景：`#0D2434`
- 软背景：`#102D42`
- 深蓝辅助：`#0A324A / #0E405D`

现在深色模式会保留Valora的蓝色品牌氛围，而不是单纯黑底。

### 3. 修正深色模式可读性

已修正：

- Snackbar 深色模式下白底白字的问题；
- 部分标签在深色模式下仍然使用接近黑色文字的问题；
- 图标编辑按钮深色模式下的纯灰圆背景，改成深蓝半透明背景；
- 设置页顶部 Hero 深色模式改为深蓝渐变。

### 4. Dock 与保存按钮暗色视觉

深色模式下的液态玻璃现在采用：

- 轻量实时模糊；
- 深蓝半透明主体；
- 品牌蓝边缘轮廓光；
- 去除大面积反光；
- 保留细边缘光。
