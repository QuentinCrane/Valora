# v9 UI refinement report

本轮按用户反馈做了以下调整：

1. 删除 mock / demo 数据：首次启动不再生成示例资产、心愿、分类、标签；设置里的“重置示例数据”改为“清空本地数据”。
2. 强化底部导航液态玻璃：提高 blur、透明渐变、边框高光和浮层阴影，左侧 Dock + 右侧黑色加号维持分组。
3. 扩大震动反馈覆盖：导航、加号、返回、筛选、分类、弹层、保存、设置项等关键交互增加 haptic。
4. 缩窄页面边距：默认页边距降低，新增页、心愿页、编辑页同步收窄。
5. 动画调整：页面切换改为淡入 + 轻缩放的渐变式过渡；卡片入场改为柔和 fade/scale。
6. 首页数字动效：资产总值增加翻动/滚动式停靠动画；小数字增加 AnimatedSwitcher 过渡。
7. 返回入口增强：子页面返回按钮改成带“返回”文字的玻璃胶囊，避免用户感觉返回入口消失。
8. 设置页统一美术：SettingRow 改成自绘紧凑卡片行，字体、间距、图标和全局卡片风格统一，避免字体过大。
9. 首页减负：钱包漏洞、到期提醒等偏分析内容从首页迁移到分析页。

仍需在本机 Flutter 环境执行：

```bash
flutter clean
flutter pub get
dart format .
flutter analyze
flutter build apk --debug
```
