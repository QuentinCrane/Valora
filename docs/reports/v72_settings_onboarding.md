# v72 设置页二级菜单与新手教程

## 设置页重构

设置页不再使用顶部 Tab 分页，而是改成更接近系统设置的列表式入口：

- 数据与备份
- 外观与交互
- 系统与权限
- 新手教程

点击前三个入口会进入独立二级设置页。原有分类、标签、备份、云端、外观、触感、贴纸引擎、系统权限、小组件、通知等功能仍复用原本源码中的真实设置组件，没有改成凭空页面。

## 新手教程

新增首次启动教程：

- 第一次打开 App 时自动出现
- 也可以在设置首页的“新手教程”重新打开
- 教程覆盖：资产/心愿、封面制作、附加项目、日均成本、价值回收、分析复盘、备份迁移、设置系统能力

## 数据字段

`AppSettings` 新增：

```dart
bool onboardingCompleted
```

用于记录是否已经完成或跳过首次教程。旧数据默认 `false`，因此升级后第一次进入会显示教程。
