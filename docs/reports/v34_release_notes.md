# v34 完整版：心愿封面与贴纸能力补齐

## 本版重点

### 1. 心愿新增页补齐「选封面 / AI贴纸」
在底部加号进入的新增页面中，切到“心愿”后，现在也会显示：
- 选封面
- AI贴纸

不再只有资产模式才有封面入口。

### 2. 心愿编辑页补齐封面入口
在“编辑心愿 / 新增心愿”的独立页面中，图标预览下面新增：
- 选封面
- AI贴纸

因此心愿和资产的封面能力保持一致。

### 3. 心愿列表支持真实图片 / 贴纸封面显示
心愿卡片不再把 `file://...` 当普通文字展示，而是走统一的 `ValoraIconVisual` 渲染链路。

### 4. 保留 v33 轻量贴纸引擎能力
继续保留：
- 轻量 / 均衡 / 精细 三档本地贴纸模式
- 多候选贴纸选择
- 未选候选图自动清理
- Android ABI 拆分与 release 资源压缩

## 备注
v34 主要是把“心愿”链路补齐，让资产、心愿在封面与贴纸能力上保持一致。
