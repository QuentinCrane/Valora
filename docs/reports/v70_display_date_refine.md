# v70 显示与日期选择修正

本版基于 v69 源码继续修复以下问题：

## 1. 首页资产卡片持有时间容易被省略
新增设置项：
- 设置 -> 外观交互 -> 显示与格式 -> 首页副信息字号

可选：
- 紧凑
- 小
- 标准
- 大

对应新增字段：
- `AppSettings.homeMetaFontScale`

首页资产网格卡片 / 列表卡片中的“价格 / 已使用时间”等副信息，会根据该设置调整字号。

## 2. 资产详情页持有时间可点击查看说明
资产详情页顶部的“持有时间”指标现在可以点击，弹出“持有时间说明”小弹窗，显示：
- 购买日期
- 当前计算截止日期
- 原始天数
- 当前设置下的显示方式
- 计算口径说明

## 3. 贴纸模式背景改为纯白
首页贴纸模式下的浅色彩纸背景改为纯白，避免同一模式里出现偏黄、偏蓝、偏绿等不统一的底色。

## 4. MaterialDatePicker 继续修色和错位
保留 `MaterialDatePicker.Builder.datePicker()`，没有退回旧 `DatePickerDialog`。

调整：
- 日期数字保留系统默认字体 padding，避免垂直错位
- DatePicker 日/年单元尝试应用圆角矩形 `itemShapeAppearance`
- 按钮和日期文字继续强制Valora蓝/深蓝
- 弹窗继续白底圆角
- 运行时补色追加一次延迟执行，减少部分 ROM 主题不生效的问题
