# v71 附加项目、首页时间和卡片金额修正

## 1. 附加项目支持直接编辑 / 删除
资产编辑页的附加项目列表现在不再只能长按删除：
- 点击条目可编辑
- 右侧有编辑按钮
- 右侧有删除按钮
- 编辑弹窗内也可以删除

## 2. 附加项目购买时间支持跟随父资产
新增附加项目时默认启用“购买时间跟随父资产”。
也可以关闭后单独选择附加项目购买时间。

数据字段新增：
- `followParentPurchaseDate`

旧数据兼容：没有该字段时默认为 `false`。

## 3. 首页卡片统一显示天数
首页资产卡片不再同时显示天数、年/月，统一显示：

```text
已使用 N 天
```

点击卡片里的副信息区域，会弹出持有时间明细，展示：
- 首页显示天数
- 年/月换算
- 购买日期
- 计算截止日期

## 4. 首页卡片副信息自适应字号 / 换行
当金额和持有天数过长时，副信息会自动略微缩小字号并允许两行显示，减少省略。

## 5. 首页卡片金额和日均成本计入附加项目
首页卡片显示金额改为：

```text
资产本体价格 + 计入总资产的附加项目
```

日均成本仍使用现有 `asset.dailyCost`，即：

```text
资产本体 + 计入日均成本的附加项目
```

这样附加项目会真正影响首页卡片上显示的总价值和日均成本。
