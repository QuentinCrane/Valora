# v43 智能管理与直接选择优化

这版主要解决：

1. 分类管理新增时还要手动输入图标和颜色，不够智能。
2. 标签管理也还要手动输入颜色。
3. 资产/心愿编辑里的标签仍然主要靠手打，不够像选择器。

## 1. 分类管理重做

分类管理现在支持：

- 输入分类名称后自动建议图标和颜色。
- 常用分类一键套用，例如手机、电脑、数码配件、摄影、游戏、服饰。
- 图标可以直接从 Emoji 图标池中点选。
- 颜色可以直接从色板中点选。
- 新增分类时不再需要手动输入十六进制颜色。
- 已有分类可以点击编辑，编辑时也可以直接点选图标和颜色。

## 2. 标签管理重做

标签管理现在支持：

- 输入标签名称后自动建议颜色。
- 常用标签一键套用，例如通勤、办公、学习、收藏、维修、长期持有。
- 颜色可以直接从色板中点选。
- 已有标签可以点击编辑，编辑时直接选颜色。

## 3. 资产 / 心愿编辑标签选择增强

资产编辑、快速新增、心愿编辑中，标签不再只能手动输入：

- 增加“选择已有标签”入口。
- 可以点选常用标签。
- 可以点选已经创建过的标签。
- 仍然保留手动输入，兼容原来的输入方式。

## 4. 技术改动位置

主要改动：

- `lib/src_parts/features_settings.dart`
  - 新增智能分类/标签色板和图标池
  - 重写 CategoryManager
  - 重写 TagManager

- `lib/src_parts/features_asset_editor.dart`
  - 资产编辑页增加标签选择器

- `lib/src_parts/features_wishes.dart`
  - 快速新增页增加标签点选
  - 心愿编辑页增加标签点选
