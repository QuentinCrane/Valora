# V15 图标库扩展与白色画布精修报告

## 本轮目标

根据最新反馈，本轮重点不再改动业务结构，而是解决两个体验问题：

1. 新增页中的「Emoji / 3D 图标 / 相册」资源量不足，且 3D 图标与普通 Emoji 的视觉区分不明显；
2. 页面整体背景偏灰，希望恢复更干净的白色画布。

## 已完成改动

### 1. Emoji 图标库扩容

`common_widgets.dart` 中的 `kEmojiIconLibrary` 已重新扩展，增加更多分类与图标：

- 全部
- 数码
- 电器
- 家居
- 交通
- 穿搭
- 娱乐
- 运动
- 收藏
- 办公
- 食品

本轮采用 Unicode Emoji 字符作为资源，避免引入第三方图片资产，保持 clean-room 实现。

### 2. 3D 图标库重做

新增 `Valora3DIconSpec` 和 `kThreeDIconSpecs`。

3D 图标不再只是普通 Emoji 的重复展示，而是使用：

- `z3d:*` 语义值；
- 渐变背景；
- 高光圆形；
- 柔和阴影；
- 右上角 sparkle；
- 独立的 3D 卡片视觉。

当前覆盖：

- 数码设备
- 电器
- 生活家居
- 穿搭
- 交通
- 价值资产
- 娱乐收藏

### 3. 相册封面入口扩展

`kAlbumIconLibrary` 从简单占位扩展为：

- 相册
- 票据
- 风景
- 质感
- 生活

相册模式仍保留「从系统相册选择真实封面」按钮；下方封面贴纸只是轻量备选。

### 4. 白色背景替换

全局浅色背景调整：

- `kBg` 从 `#F3F3F4` 调整为 `#FFFFFF`；
- `scaffoldBackgroundColor` 浅色模式明确使用 `Colors.white`；
- `GradientScaffold` 浅色模式由灰蓝渐变改为纯白画布。

页面卡片、筛选胶囊、底部液态玻璃等仍保留轻微层次，以避免全白页面没有结构。

## 版本信息

- Flutter 版本号：`0.15.0+15`
- Android `versionCode`: `15`
- Android `versionName`: `0.15.0`

## 建议后续继续优化

1. 若后续要真正做到更接近高质量 3D 图标，可以引入自制 PNG/WebP 图标资产，并统一放入 `assets/icons_3d/`；
2. 当前为了保持包体小和版权安全，没有下载或内置第三方图标包；
3. 如果要跨设备保持完全一致的 Emoji 样式，可以后续评估引入开源 emoji 字体，但这会增加包体并可能影响渲染性能。
