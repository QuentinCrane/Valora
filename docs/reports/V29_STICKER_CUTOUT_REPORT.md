# V29 贴纸抠图封面增强说明

本版专门增强“抠图形成封面 / 贴纸”的算法和体验，不再只根据角落背景颜色做简单透明化。

## 核心改动

### 1. 边缘感知背景分割

Android 原生层 `MainActivity.java` 中新增 `createEdgeAwareStickerCutout()`，抠图流程改为：

1. 读取图片并缩放到最大边 1280；
2. 从四边采样估计背景颜色均值与背景波动；
3. 用 Sobel 梯度计算边缘强度；
4. 从图片边缘开始做 flood fill 背景生长；
5. 生长时同时参考：
   - 与边缘背景色的距离；
   - 亮度差异；
   - Sobel 边缘强度；
6. 高梯度边缘会阻止背景继续向物体内部扩散。

这样比原来的“只扣颜色”更适合商品图、浅色桌面图、白底物品图。

### 2. Mask 清理与兜底

新增：

- 孤立噪点清理；
- 小空洞填补；
- 前景比例异常检测；
- fallback 前景 mask。

如果边缘分割结果过小或过大，会回退到更保守的颜色距离分割，避免生成纯透明图或整张原图。

### 3. 贴纸描边与光影

抠图输出不再只是透明 PNG，而是：

- 透明背景；
- 物体主体；
- 白色贴纸描边；
- 轻微品牌蓝柔光阴影。

输出仍保存为 PNG，路径格式为：

```text
file:///data/user/0/com.valora.assets/files/valora_media/cutout_xxx.png
```

### 4. UI 文案调整

新增页、编辑页、原生测试面板中，“抠图封面”完成后提示改为“已生成贴纸封面”。

## 当前算法边界

这版没有引入 OpenCV / 服务器抠图 / 在线 AI 分割，因此仍然是离线启发式算法。效果最好的是：

- 白底商品图；
- 浅色桌面上的物品；
- 背景和主体颜色差异明显的照片；
- 主体没有贴住图片四边。

复杂场景仍可能不完美，例如：

- 主体和背景颜色非常接近；
- 背景纹理非常复杂；
- 主体贴边；
- 人像、毛发、透明材质。

后续如果要进一步提升，可以接入：

1. OpenCV GrabCut；
2. ML Kit Selfie Segmentation，偏人像；
3. MediaPipe Image Segmenter；
4. 端侧轻量 U^2-Net / MODNet / RMBG 类模型；
5. 服务器侧 AI 抠图 API。
