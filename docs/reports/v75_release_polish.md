# Valora V75 发布前细节优化

本版本基于 V74 真实控件定位教程版继续做发布前硬化，重点处理正式发布前容易影响观感、性能和可理解性的细节。

## 1. 设置页到分析页性能优化

- 新增 `AnalyticsSnapshot` 聚合缓存，缓存分析页首屏常用数据：资产总值、平均日耗、累计投入、心愿预算、分类分布、标签分布、日均成本排行、长期价值趋势和资产体检建议。
- 在首页 Shell 中增加分析数据预热：首次进入主界面后、切到设置页或分析页时，会提前构建分析缓存，减少从设置页切回分析页时的首帧计算压力。
- 当资产、心愿、分类、标签、回收记录、设置等影响分析结果的数据发生变化时，会主动失效缓存，避免展示旧结果。

## 2. 首页资产图标跨设备统一

- 首页资产图标改为固定方形渲染 + `RepaintBoundary` + 禁止文本缩放影响 emoji 的方案。
- 相册封面 / 贴纸图标增加 `cacheWidth/cacheHeight`，避免高分辨率图片在小图标场景反复大图解码。
- 去掉资产卡片图标里的固定偏移，让不同屏幕尺寸、系统字号和像素比下的视觉中心更一致。

## 3. 日期选择器与日期显示

- Flutter 侧加入统一的 `DatePickerThemeData`，让日期选择器颜色跟随Valora主色 `#7CC6F2` 和现有深浅色主题。
- 表单日期输入的提示文字缩短，帮助文案和错误文案允许两行显示。
- 表单行 `FormLine` 和右侧日期文本不再强制单行省略，允许自然换行，避免日期/分类/标签在窄屏设备上被截断。

## 4. 新手教程补全贴纸功能说明

- 教程新增独立锚点：`选封面`、`裁切白框`、`手动勾勒`、`AI贴纸`。
- 不再只高亮整条导入栏，而是分别指向每个真实按钮，并解释它们的使用场景差异。
- 手动勾勒说明强调“按路径生成主体轮廓”，AI 贴纸说明强调“候选图 + 描边/阴影/边缘调整”。

## 5. 贴纸实时预览和速度优化

- 手动勾勒预览增加图片尺寸缓存，避免重复读取和解码尺寸。
- 候选贴纸图、手动勾勒背景图使用预览尺寸缓存，降低大图在预览场景的解码成本。
- 勾勒层使用 `CustomPaint` 复制当前点列表并基于点数/首尾点判断重绘，修复列表原地修改导致预览可能不刷新的问题。
- 勾勒点采样间隔略微增大，减少高频触摸事件下的重绘次数，提升实时预览跟手性。
- 最终生成手动贴纸时，对超大原图按最长边 1800px 下采样后再生成，减少生成等待和内存压力。
