# V17 Dock 滑动与选中反馈修正报告

## 本轮目标

针对“底部 Dock 选中反馈不好看、希望能在 Dock 上通过滑动切换，而不是只能点击”的反馈，对底部导航交互做专项修正。

## 主要修改

1. **真正支持 Dock 内横向滑动选择**
   - 在 Dock 胶囊区域内横向拖动时，会根据手指所在位置预览目标 Tab。
   - 手指滑过不同 Tab 时触发轻微震动。
   - 松手后切换到当前预览的 Tab。
   - 仍然保留点击 Tab 切换。

2. **选中态反馈重做**
   - 移除原先偏“白色矩形按钮”的选中反馈。
   - 改成液态玻璃高光 Thumb，在图标下方滑动。
   - Thumb 采用半透明白色 + 品牌蓝渐变 + 毛玻璃模糊 + 微弱阴影。
   - 选中图标有轻微放大和底部蓝色短条。

3. **滑动时增加手指光晕**
   - 拖动 Dock 时，手指附近会出现轻微的圆形高光。
   - 使用户明确知道 Dock 正在处于滑动选择状态。

4. **震动反馈更细**
   - 进入滑动状态：轻震。
   - 滑过新 Tab：轻震。
   - 松手切换成功：中等震动。
   - 未切换：轻震。
