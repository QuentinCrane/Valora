# Valora使用教程

## 首页

首页主要用于快速查看和管理资产。

- 顶部卡片显示资产总览、总资产、日均成本、服役/退役/卖出数量。
- 资产卡片显示资产名称、价格、使用天数和日均成本。
- 点击资产卡片进入详情页。
- 右上角搜索按钮用于搜索资产。
- 右上角下拉按钮用于筛选。
- 底部 Dock 可点击，也可以在 Dock 胶囊区域左右滑动切换页面。
- 右下角加号用于新建资产或心愿。

## 新建资产 / 心愿

点击右下角加号进入新建页。

- 顶部可切换“资产 / 心愿”。
- 图标区域可以选择 Emoji、3D 图标或相册图片。
- 资产可以填写价格、购买日期、类别、标签、目标成本、附加物品、备注、到期提醒。
- 保存按钮使用水滴液态玻璃样式。

## 分析页

分析页承接原首页中过重的统计内容，包括：

- 资产健康度
- 钱包漏洞警报
- 生命周期账本
- 资产时光机
- 到期提醒
- 长期价值曲线

## 备份、恢复与同步

在“设置 -> 数据与备份”中可以选择结构化 JSON、CSV、Markdown 报告或完整 ZIP：

- JSON 适合跨版本迁移结构化数据，但不包含封面媒体。
- 完整 ZIP 包含脱敏 JSON、CSV、Markdown、SQLite 副本、媒体清单和媒体文件；恢复前会先预检并创建恢复点，提交失败会回滚。
- 导出文件由系统文件选择器保存到你选择的位置。不要把包含个人资产或服务器信息的备份直接发到公开渠道。

在“设置 -> 云同步”中按需启用 WebDAV、坚果云或 Nextcloud。正式服务使用 HTTPS；首次上传和后续上传都会校验远端状态，发生 ETag/内容冲突时需要你明确选择保留本机或从云端恢复，不会静默覆盖另一份数据。自动上传需要打开“保存后自动上传”，并由 Android 后台任务在有网络时执行。

## 贴纸与主体分割

首次使用主体分割可能显示“模型下载中”，完成后显示“模型已就绪”。如果模型不可用，Valora 会标明不可用状态并使用离线轮廓回退；这不代表 APK 内置了独立的本地 TFLite 模型。生成候选后请先预览，再选择或手动修边，避免未经确认的结果直接替换封面。

## 通知与桌面小组件

- Android 13+ 需要在系统提示中允许通知，才能接收到期提醒；重启、时区变化和应用升级后，已启用的提醒会重新同步。
- 设置页可手动刷新桌面小组件。小组件只读取应用写入的本地摘要，不直接访问云端；资产、心愿、日均成本、到期和快照等不同卡片会按变更范围更新。

## 预测式返回测试方法

1. 确认手机是 Android 13 或更高版本。
2. 系统导航方式选择“手势导航”。
3. 打开Valora，点击资产进入详情页。
4. 从屏幕最左边缘缓慢向右滑动。
5. 如果系统支持，会看到页面随手势返回的预测动画。

如果没有效果，请检查：

- 是否用了三键导航；
- 是否在首页根页面测试，首页根页面没有上一页可预测；
- Flutter SDK 是否太旧；
- 是否安装的是旧 APK，没有重新安装最新构建。

## 编译

```bash
flutter clean
flutter pub get
dart format .
flutter analyze
flutter build apk --debug
```

APK 输出位置：

```text
build/app/outputs/flutter-apk/app-debug.apk
```
