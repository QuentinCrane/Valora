# Valora使用教程

## 首页

首页主要用于快速查看和管理资产。

- 顶部卡片显示资产总览、总资产、日均成本、服役/退役/卖出数量。
- 资产卡片显示资产名称、价格、使用天数和日均成本。
- 点击资产卡片进入详情页。
- 右上角搜索按钮用于搜索资产。
- 右上角下拉按钮用于筛选。
- 底部 Dock 可点击，也可以在 Dock 胶囊区域左右滑动切换页面。
- 右下角加号用于新建资产或心愿。

## 新建资产 / 心愿

点击右下角加号进入新建页。

- 顶部可切换“资产 / 心愿”。
- 图标区域可以选择 Emoji、3D 图标或相册图片。
- 资产可以填写价格、购买日期、类别、标签、目标成本、附加物品、备注、到期提醒。
- 保存按钮使用水滴液态玻璃样式。

## 分析页

分析页承接原首页中过重的统计内容，包括：

- 资产健康度
- 钱包漏洞警报
- 生命周期账本
- 资产时光机
- 到期提醒
- 长期价值曲线

## 预测式返回测试方法

1. 确认手机是 Android 13 或更高版本。
2. 系统导航方式选择“手势导航”。
3. 打开Valora，点击资产进入详情页。
4. 从屏幕最左边缘缓慢向右滑动。
5. 如果系统支持，会看到页面随手势返回的预测动画。

如果没有效果，请检查：

- 是否用了三键导航；
- 是否在首页根页面测试，首页根页面没有上一页可预测；
- Flutter SDK 是否太旧；
- 是否安装的是旧 APK，没有重新安装最新构建。

## 编译

```bash
flutter clean
flutter pub get
dart format .
flutter analyze
flutter build apk --debug
```

APK 输出位置：

```text
build/app/outputs/flutter-apk/app-debug.apk
```
