# 值谱 Valora v0.80.0

这是 v0.79 首个公开版本后的第一轮体验打磨更新。本次重点围绕 **液态玻璃视觉、Android 预测式返回、Dock 交互、新手教程、小组件、贴纸模式与安装包体积** 做了系统优化，让 Valora 的整体手感更顺、更清晰，也更接近 0.79 中干净通透的毛玻璃风格。

## 新增与优化

### 液态玻璃与毛玻璃体验

- 重新调整底部 Dock、添加按钮、保存按钮、取消按钮等位置的液态玻璃效果。
- 液态玻璃统一采用更接近真实镜片的 **形状折射**，折射会沿圆角矩形边缘变化，而不是简单径向扭曲。
- 玻璃边缘统一使用 **Optical Border 光学边界**，减少死白、脏边和过厚边框，让边缘高光更自然。
- 恢复更清晰的玻璃捕获参数，提升折射细节和背景透视清晰度。
- 调整普通毛玻璃按钮的透明度、模糊强度和顶部高光，减少泛白、发灰和“白色长条”观感。
- 返回按钮、普通小控件继续保持轻量毛玻璃方案，避免所有小组件都走重 shader 导致卡顿。

### Dock 交互升级

- Dock 支持按压 / 滑动时的非线性放大反馈。
- 图标会根据手指距离产生类似 macOS Dock 的弹性放大效果。
- 液态玻璃模式下，Dock 的 lens 本体也会参与动画，不再只是图标单独放大。
- 优化 Dock 的内部高光和背景模糊，减少蓝色光斑和过亮反光。
- 手指离开后 Dock 会平滑回缩到正常尺寸。

### Android 预测式返回修复

- 恢复 Android 系统预测式返回支持。
- 路由切换重新接入 Flutter 的 `PredictiveBackPageTransitionsBuilder`。
- 修复自定义页面转场导致预测式返回退化的问题。
- 返回过程减少中心缩放、裁切、重阴影等干扰，过渡更接近系统原生手感。
- 设置页等二级页面返回时更加顺滑，减少闪动和卡顿。

### 新手教程优化

- 首次启动不再直接强制进入教程 Overlay。
- 未完成教程时，会先弹出确认提示，由用户选择是否开始教程。
- 只有真正走完教程并点击完成，才会记录为已完成。
- 选择“暂不”不会误写入完成状态，下次打开仍可继续提示。
- 教程目标定位更稳定，减少因为页面未渲染完成导致的错位或无法完成问题。
- 小屏设备上的教程说明区域增加滚动和尺寸保护，避免按钮被挤出屏幕。

### Android 小组件升级

- 新增 `值谱｜轻量卡片` 2x1 小组件，用于快速查看总资产与日均成本。
- 所有小组件增加 Android 12+ 预览布局和尺寸约束。
- 小组件整体视觉统一为更清爽的圆角卡片风格。
- 快捷记录小组件从系统按钮改为可点击文本卡片，观感更接近原生桌面组件。
- 针对 HyperOS / MIUI / 小米 / 红米 / POCO 设备增加更紧凑的小组件布局适配。

### 贴纸模式优化

- 首页贴纸模式卡片在浅色模式下统一为白色纸片风格。
- 调整贴纸倾斜角度和阴影，增强轻微悬浮感。
- 深色模式下贴纸卡片跟随卡片模式切换为暗色表面，避免白色纸片在暗色界面中过于突兀。
- 优化贴纸封面在首页中的展示尺寸和视觉一致性。

### 发布体积与构建优化

- Release 包默认聚焦 `arm64-v8a`，减少不必要的 ABI 体积。
- 仅保留中文和英文资源配置。
- 继续启用 `minifyEnabled` 与 `shrinkResources`。
- 排除部分非运行所需的 META-INF 资源。
- 保持本地优先数据策略，不加入会员、VIP 或支付功能。

## 修复

- 修复部分页面切换动画卡顿的问题。
- 修复 Android 预测式返回失效的问题。
- 修复液态玻璃折射不够清晰的问题。
- 修复部分毛玻璃表面出现过长白色高光条的问题。
- 修复返回按钮、Dock、保存按钮等玻璃控件在浅色背景下过度泛白的问题。
- 优化教程 Overlay 过早关闭、目标定位不稳定、完成状态误写入等问题。
- 优化 Dock 按压反馈突兀、图标跳变和玻璃边缘过亮的问题。
