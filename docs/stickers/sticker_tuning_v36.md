# v36 贴纸微调版

这版在 v35 的“候选选择 + 显示调整”基础上，继续增加了两个面向结果控制的能力：

1. **边缘保留微调**
   - 往左：更容易去掉边缘残留
   - 往右：尽量保留更多细小边缘

2. **颜色清理**
   - 不清理颜色
   - 去白边
   - 去黑边
   - 去角落残色（根据贴纸边缘区域自动估计）
   - 并可调“颜色容差”

## 目标
让用户在最终落地成品前，对抠图边缘和残色有更细的掌控，而不是只能反复重新抠图。

## 当前实现说明
颜色/边缘微调是在保存调整后的贴纸时应用到 PNG 像素上的，因此它属于**结果修饰层**，不是重新跑一次底层分割模型。

## 适合解决的问题
- 贴纸边缘有一圈浅色残留
- 黑底或深色背景留下脏边
- 主体边缘太干净导致细节被吃掉
- 想稍微多保留一点头发/细长边缘/透明边
