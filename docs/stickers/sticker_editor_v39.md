# v39 手动修边版

这版主要做了两件事：

1. **修图/修边界面重新布局**
   - 预览区固定在上方，尽量更大。
   - 下方参数区滚动显示，不会再把很多选项挤没。
   - 底部操作按钮固定，避免滚动到底部才能保存。
   - 工具、构图、智能边缘优化分块显示，更容易理解。

2. **加入手动局部修边**
   - `移动`：拖动贴纸位置。
   - `橡皮`：在预览图上直接擦掉多余部分。
   - `恢复`：把误擦掉的部分恢复回来。
   - 支持 `笔刷大小`、`撤销修边`、`清空修边`。

## 技术说明
- 手动修边不是只画一层假蒙版，而是会在最终导出的 PNG 上真正应用。
- 当前做法是在最终画布 RGBA 像素上应用橡皮/恢复笔刷：
  - 橡皮：把对应区域 alpha 清零
  - 恢复：从原始实时预览的 RGBA 中拷回对应区域
- 这样能保证预览和最终输出结果尽量一致。

## 已知限制
- 目前恢复笔恢复的是“当前智能边缘优化后”的内容，而不是从原始照片重新分割。
- 如果想继续提升，下一步可以做：
  1. 局部缩放画布
  2. 棋盘透明背景
  3. 笔刷硬度/羽化
  4. 自动描边与阴影
