# v40 更智能的手动抠图版

这版主要解决两个问题：

1. **手动修边还不够像“手动抠图”**
2. **希望换一个更厉害的识别模式，而不是只有简单后处理**

## 这版做了什么

### 1. 手动修边从“画布层修改”升级为“源图层修改”
之前橡皮/恢复更偏向在最终预览画布上修修补补。
这版会先把用户笔刷坐标反算回原始贴纸图像坐标，再直接修改源 RGBA：
- 橡皮：把该区域 alpha 清零
- 恢复：从处理后的源图像里恢复该区域

这样更接近真正的“手动抠图”，而不是只在结果图上盖一层。

### 2. 新增识别模式（本地）
新增 4 种识别模式：
- **标准**：平衡模式
- **主体优先**：尽量保住主体，适合容易被吃掉的物体/人物
- **边缘优先**：更注重细边缘
- **强力去底**：更激进地去掉背景残留

这些模式会影响：
- alpha 截断阈值
- 边缘保留/收缩强度
- 颜色清理容差的行为

### 3. 仍然保留手动修边
- 移动
- 橡皮
- 恢复
- 笔刷大小
- 撤销修边
- 清空修边

## 注意
这版仍然没有真正替换成一个体积更大的新模型（例如更重的 TFLite 分割模型），而是：
- 在现有本地引擎之上，
- 增强识别模式，
- 并把手动修边改成更有效的“源图层抠图”。

如果后续继续做，可以考虑：
1. 再加一个更重但可选下载的高质量模型包
2. 加入局部放大镜
3. 透明棋盘背景
4. 笔刷羽化/硬度
