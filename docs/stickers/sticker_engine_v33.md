# v33 轻量本地贴纸引擎

这版重点解决两个问题：
1. **安装包和运行开销不要失控**。
2. **贴纸抠图仍然尽量稳**。

## 主要变化

### 1. 引入三档本地贴纸模式
- **轻量 compact**：输入图最大边约 960，候选更少，优先控制速度与体积。
- **均衡 balanced**：输入图最大边约 1280，默认推荐。
- **精细 quality**：输入图最大边约 1600，候选更多，效果更稳但更慢。

### 2. 设置页可直接切换
在“设置 -> 原生 -> 贴纸引擎”中可切换模式。

### 3. 默认自动清理未选候选贴纸
候选图在用户选定后会自动删除未被选中的 PNG，避免缓存越积越多。
如需调试，可开启“保留未选候选图”。

### 4. 安装包体积优化
Android 侧已启用：
- ABI 拆分（arm64-v8a / armeabi-v7a）
- release 资源压缩
- release 混淆/瘦身

## 实际意义
这版并没有贸然把大体积离线模型直接塞进 APK，而是先把“**可控体积 + 可选模式 + 自动清理**”这条链路做好，方便下一版继续接真正的轻量 TFLite 分割模型。

## 下一步建议
v34 再继续接一个真正的轻量前景分割 `.tflite` 模型，优先放在 `android/app/src/main/assets/models/`，并纳入当前三档模式中统一调度。
