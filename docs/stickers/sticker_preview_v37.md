# v37 实时预览修正版

## 为什么之前调节“没有反应”
因为 v36 的边缘保留 / 颜色清理逻辑，**只在点击“保存调整后的贴纸”时才真正处理 PNG**。
也就是说：
- 你拖动和拉滑杆时，看见的仍然主要是原图/原候选的显示预览；
- 所以用户体感上就像“根本没反应”。

## v37 做了什么
1. 把调整逻辑抽成了 `renderAdjustedStickerPngBytes(...)`。
2. 预览组件改成 Stateful + FutureBuilder。
3. 当这些参数变化时会**重新处理预览图**：
   - 完整显示 / 铺满
   - 缩放
   - 拖动位置
   - 边缘保留
   - 颜色清理模式
   - 颜色容差
4. 预览区左上角新增“实时预览”标记。
5. 按钮文案更明确：
   - 使用原候选
   - 应用调整并生成贴纸

## 结果
现在用户在调节时，预览会实时变化，不再是“拉了也没反应”。
