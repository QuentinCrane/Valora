# v38 贴纸编辑器调研与修正说明

## 结论
真正好用的贴纸抠图不是只靠一次 AI 分割，而是组合：

1. 自动前景分割：先得到主体 mask。
2. 边缘细化 / alpha matte：把硬 mask 变成更自然的透明边缘。
3. 交互式修正：用户用笔刷、前景/背景提示或颜色清理纠正错误。
4. 实时预览：所有参数变化必须即时反馈，否则用户无法判断调整是否有效。
5. 输出层处理：统一画布、留白、描边、阴影、透明 PNG。

## v38 实施内容

- 调整弹窗改为可滚动的 90% 高度面板，避免选项显示不完整。
- 边缘保留不再只是保存时一次性处理，而是继续保留实时预览机制。
- 边缘算法从简单 alpha cutoff 改为基于透明邻域的 boundary-aware 处理。
- 去白边 / 去黑边 / 去角落残色改为优先作用于边界像素，减少误伤主体内部颜色。
- 文案说明和按钮保留 v37 的实时预览逻辑。

## 后续更强路线

下一步建议继续做两件事：

1. 手动局部修边：橡皮擦 / 恢复画笔。
2. 原图级交互式分割：保留原图 + mask，通过用户前景/背景提示重新求 mask。

其中第二点更接近 GrabCut / trimap matting 的思路，但 Android 端会明显增加工程量。
