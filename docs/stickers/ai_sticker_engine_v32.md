# AI 贴纸引擎 v32（历史设计记录）

> 本文档保留 v32 的候选生成设计。当前实现使用 ML Kit Subject Segmentation 和离线启发式轮廓回退；`android/app/src/main/assets/models/` 只是未来 TFLite 模型的预留目录，当前 APK 未随包发布本地 TFLite 模型。

这一版的重点不是只做一次抠图，而是把封面贴纸能力改成一个**多候选引擎**。

## 目标
- 优先走本地 AI / 语义分割链路。
- 避免旧算法一次失败就把错误结果直接写入封面。
- 对边缘、白边、阴影和小物体展示做专门优化。

## 当前实现
1. **候选生成**
   - ML Kit Subject Segmentation 生成多阈值候选（保守 / 均衡 / 激进）；模型首次使用可能需要下载
   - 传统边缘感知候选作为兜底
2. **质量打分**
   - 面积占比
   - 是否过度贴边
   - 是否过空 / 过满
   - 组件集中度
3. **Flutter 侧选择器**
   - 生成后不再直接覆盖封面
   - 先让用户预览并手动选中一个候选贴纸
4. **离线模型预留接口**
   - Android 侧已预留 TensorFlow Lite 入口
   - 未来可在 `android/app/src/main/assets/models/` 中放入离线模型文件，并接入同一候选管线；当前目录没有随包模型

## 为什么这样做
旧版最大问题不是完全抠不出来，而是**偶尔会抠错且直接写入结果**。
多候选 + 质量打分 + 人工选择，可以显著降低错误进入资产封面的概率。

## 后续建议
如果你下一步真要继续把这一能力做到更稳，建议引入轻量级离线显著目标分割模型（例如 U²-NetP / 其他移动端二值前景模型），接到当前的本地候选管线中。
