# Flutter 共享转场实现与验证

## 覆盖范围

- 资产网格、列表、便利贴、首页提醒和分析排行中的资产入口，以及对应详情页。
- 资产详情到编辑页的图标，心愿卡片到心愿编辑页的图标。
- 图表卡片到详情页，以及使用时长排行、日均成本排行、价值象限详情中的资产条目；从资产返回时保留图表详情页。其他没有共享元素的页面继续使用原有路由。
- 返回使用对应的 Flutter 共享元素；快速返回、来源移除以及返回手势取消均保留可用的导航与表单状态。
- 仅在完整动画模式下启用共享转场，减少动画、关闭动画和系统禁用动画沿用现有轻量路径。

当前没有将 SharedView Kit 接入正式应用，也没有提供模拟系统 SDK 的模式开关。已验证的 SDK 限制与设备结果见 [SharedView 接入可行性](SHAREDVIEW_MOTION_FEASIBILITY.md) 和 [真机验证记录](../../experiments/sharedview_probe/VALIDATION.md)。

## 验证记录

2026-11-02，使用 Flutter 3.44.8、Dart 3.12.2：

- `flutter test --no-pub test/widget/shared_motion_test.dart test/widget/form_submission_test.dart test/accessibility/adaptive_layout_test.dart test/performance/effects_motion_test.dart`：26 项通过。覆盖三种资产视图、资产编辑、心愿编辑、图表及其资产条目、快速返回、来源移除、取消返回时输入值和焦点恢复、减少及关闭动画。
- `flutter analyze --no-pub --no-fatal-infos`：无错误和警告；保留工程原有 493 条 info 提示。
- `flutter build apk --debug --no-pub` 和 `flutter build apk --release --no-pub`：通过。
- Android 36 x86_64 模拟器，使用独立包名 `com.valora.motionfixture` 和合成数据：验证经典外观下资产网格、列表、便利贴、资产编辑、心愿编辑、图表详情、使用时长排行资产的打开和逐级返回，以及液态外观下资产详情、资产编辑和心愿编辑的打开和返回。转场录像检查了网格卡片进入和返回；模拟器检查不是性能测量。
- 同一模拟器中安装并启动 release APK，确认 `com.valora.assets` 进入首次启动界面，未观察到启动异常。该 APK 按构建时工作区生成，其中还包含本任务开始前已存在、未提交的工作区更改。

此前连接的小米真机在本轮 Flutter 验证时已离线；上述 Flutter 结果尚不构成真机手势、流畅度或性能验收。应在设备重新连接后补充真机视觉、取消/完成预测式返回和性能测试。

## 小项转场与绘制负担调整

2026-11-02：设置分组及分类、标签管理条目，首页搜索、筛选、排序及卡片内持有时间，表单中的分类、标签和选择字段，以及收益记录入口接入共享转场。日期选择、删除确认等系统或模态交互保留原有行为。减少或关闭动画时仍使用轻量路径。

共享转场的目标页不再让每张 `AppCard` 同时执行额外的入场缩放和透明度动画；飞行元素使用独立绘制边界，小项的内容按比例收放，避免长条控件被强行放大填满整页。表单卡片内补充透明 `Material`，让点击反馈能够显示。

上述相关控件、表单、无障碍与动画测试共 33 项通过；其中包含设置分组和分类编辑的逐级返回、首页排序、资产卡片内小项、选择结果及表单草稿保留。`flutter analyze --no-pub --no-fatal-infos` 无错误和警告，保留原有 493 条 info 提示。

使用独立包名和合成数据运行 `tooling/motion_profile_harness.dart` 的旧版基线，在 Android 36 x86_64 模拟器中完成 8 次资产卡片往返，采集到 574 帧，UI 构建 P95 为 2.499 ms、栅格 P95 为 17.511 ms、端到端帧跨度 P95 为 23.581 ms。该结果只描述当次模拟器运行；后续模拟器断开、运行条件不一致，未取得有效的优化前后对照，也不能据此判断真实手机的掉帧率或性能收益。需要同一手机、同一刷新率和相同场景下复测。
